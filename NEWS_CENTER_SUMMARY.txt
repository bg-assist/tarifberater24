EXECUTIVE SUMMARY
================================================================================

A fully automated, AI-powered news aggregation system that:
✓ Fetches verified news from 4 trusted German sources every 12 hours
✓ Translates and summarizes articles in Bulgarian using GPT-4o-mini
✓ Deduplicates articles using RSS GUIDs (zero redundancy)
✓ Auto-categorizes and rates importance (critical/high/medium/low)
✓ Integrates with AI Assistant for context-aware responses
✓ Provides premium mobile-first UI with featured articles section
✓ Costs only ~$0.27/month in LLM tokens
✓ Zero external dependencies (native RSS parsing)
✓ Graceful error handling and fallbacks

TECHNICAL ARCHITECTURE
================================================================================

BACKEND:
  • server/news.ts (12 KB)
    - fetchRssFeed(): Native XML parsing with regex (no external deps)
    - translateAndSummarize(): GPT-4o-mini for Bulgarian translation
    - articleExists(): Deduplication via rssGuid
    - categorizeArticle(): Keyword-based auto-categorization

================================================================================
AUTOMATION SETUP
================================================================================

Heartbeat Schedule:
  • Frequency: Every 12 hours (configurable)
  • Entry Point: POST /api/internal/news-heartbeat
  • Handler: newsHeartbeat() from server/_core/newsHeartbeat.ts
  • Timeout: 60 seconds
  • Retry: On failure, retry after 5 minutes

Execution Flow:
  1. Initialize default RSS sources (if not exists)
  2. Get all active news sources from database
  3. For each source:
     - Fetch RSS feed
     - Parse XML items
     - For each item:
       - Check for duplicates (rssGuid)
       - Translate to Bulgarian (GPT-4o-mini)
       - Categorize (keyword-based)
       - Determine importance
       - Store in database
  4. Update lastFetchedAt timestamp
  5. Return stats
